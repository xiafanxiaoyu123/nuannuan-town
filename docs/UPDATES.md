# 源码更新记录

## 家园牧场与生活玩法 · 2026-10-20

本次同步 3.0.5 源码（Android versionCode 38，对外版本仍为 3.0）。以下为源码变化说明；仓库更新不代表公开站点部署、安装包分发或物理设备验收。

- 新增家园自由牧场与第 5 级扩建：7 种动物、12 件牧场摆件，包含亲手喂食、轻刷、收蛋、挤奶、梳绒以及邀请伙伴散步时的角落回应。
- 新增家庭厨房与 24 道独立 3D 料理：备料、搅拌、翻面、烤盘、组装和摆盘；技法与原料共同决定品质，成品可摆上餐桌。
- 新增备餐清单、茶会招待、咖啡屋招牌与常客回忆；居民会记住具体田块、鱼讯与合奏选择。
- 新增 10 项永久生活发现与手账，补充夜间许愿、音乐、料理和动物散步之间的小彩蛋。
- 附近交互移至右下角，按钮等宽等高、最多显示 3 项，可滑动查看，并支持大字、摇杆避让和长文案换行。
- 修复钓鱼收线面板遮挡与取舍选择，完善暂停恢复、跨档旧控件和奖励保存衔接。
- 服务端礼包目录与存档校验同步 pantry/dishes 类型；统一免费与支付关闭状态保持不变。

## 存档、后端与玩法修复 · 2026-10-17

- 同步新增农作物、果树、家具、软装配色、家园料理、迎宾礼与周常等当前玩法，以及小游戏双模交互、连击和熟练度、衣橱与装修筛选、拍照辅助线和滤镜。
- 统一花肥库存，幂等迁移旧档两个存储位置；兼容画框主题名称与历史数字，修复小游戏和收获周常统计，保留已领状态及可确认进度。
- 服务端复用客户端纯数据存档校验；补齐同步、礼包、邮件的版本与事务保护，非法输入不覆盖有效云档，溢出整笔回滚，重试不重复发放。
- 补齐可信代理、精确来源白名单、账号失败冷却和 Bearer 退出；微信响应断流、验签及退款待核对使用离线夹具验证。
- 同步账号工作台源码、工程工具及相关回归入口，新增 `npm run qa:backend`。部署配置见 [账号服务说明](ACCOUNT_SERVICE.md)。支付和原项目外部服务连接保持关闭。

这些内容来自同一份冻结源码；GitHub 同步是源码交付，不代表线上部署、真机安装或真实支付验收。

## 2.1.14 · 2026-10-17

本次同步最新的游戏源码，包含以下调整：

- 裁缝铺改为场景内的四条透视轨道，保留近大远小的布面；扩大手机操作区和底部按键。收窄多余桌沿及机架，为暖暖和大喵留出完整站位，避开轨道和操作区域。
- 将玩家、物品、服装、每日订单等共享数据整理到 `js/shared/`，每日订单逻辑独立为 `js/features/daily/`，并拆分 Town、装修及主界面模块。
- 增加默认关闭的只读诊断面板，细分主场景、阴影和后处理的绘制统计；装修工具栏按实际变化范围刷新，静态景物减少重复绘制调用。整体帧率与发热仍需在目标设备验证。
- 修复每日订单无尽模式小数秒进度的存档校验，保留旧档导入、恢复点和奖励去重；补充内存存档回归检查。
- 整理家具拖动、巨大作物收纳及展示、秋千模型和航行焦点等交互细节。

# Windows 解压位置与长路径启动

增加自包含原生入口，在用户选择的普通解压位置启动；支持中文、空格和长路径，逐文件校验运行缓存。保留现有玩法、用户数据路径与存档。构建与验收现在区分路径长度和 Windows 低完整性安全标记，保持 Electron 渲染沙箱。Windows 源码构建需额外安装 requirements-windows-build.txt；玩家无需 Python。
